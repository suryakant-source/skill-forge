# SkillForge - Learning & Career Tracker

## What is SkillForge?
A full-stack platform where students can track their learning journey,
manage goals, complete tasks, and get AI-powered career advice.

## Project Structure
skillforge/
├── skillforge-backend/   → Spring Boot REST API
├── skillforge-web/       → React + Vite Web App
├── skillforge-mobile/    → React Native + Expo Mobile App
└── docs/                 → Architecture diagrams and notes

## Tech Stack
- Backend:  Java 17 + Spring Boot 3.x
- Frontend: React + Vite + Tailwind CSS
- Mobile:   React Native + Expo
- Database: PostgreSQL
- Auth:     JWT (JSON Web Token)
- AI:       Ollama (Local AI Model)
